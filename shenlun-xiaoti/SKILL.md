# 申论小题

**本 skill 只管小题**（归纳概括／综合分析／对策／公文）。大作文见 `shenlun-dawenti`；
图片输入、真题识别、错题库、导出见 `shenlun-router`。

## 一、解题流程（门控）

> ⛔ **不要照本文件产出答案**——本文件只给流程与门控，**各版答案的方法论依据在名师库**。
> （旧版把一份"压缩版"流程内联在主文件里，结果两版答案长得一样——那正是名师库失效的原因。）

0. **先读名师库**（白鹭、小马哥各读一遍），读完再动笔；只读本文件摘要等于没做
1. 判题型与要素
2. **【门控】读白鹭** `references/bai-lu-methodology.md` → 取其**审题法与阅读法**
3. **【门控】读小马哥** `references/xiaoma-methodology.md` → 取其**结构逻辑**
4. **【门控·公文题专属】读公文格式规范** `references/gongwen-format-rules.md` → 先定文种格式与占格，再谈内容
5. 分别产出**两版作答**，**两版必须结构性地不同**（若只是换措辞，说明没真按各自方法论产出，须重做）
   - 若用户只要一版，按用户指定输出
6. **给"差异对照"，不只是两个分数**

### 题型判定

| 题干关键词 | 题型 |
|---|---|
| 概括/梳理/总结/提炼/归纳 + 问题/原因/做法/经验/成效/变化/特点 | 归纳概括题 |
| 分析、理解、评析、认识、看法、谈谈为什么 | 综合分析题 |
| 提出/建议/对策/启示 | 对策启示题 |
| 写一份/起草/拟写 + 文种 | 公文写作题 |

### 两版结构特征

| | 小马哥版 | 白鹭版 |
|---|---|---|
| **结构特征** | **结构固定、要素融合**——一律「上位概括词 + 具体做法」 | **结构随题干、要素分栏**——题干有几个要素/对象/主体就分几栏 |
| **排版** | 按大条独立分段，每条控制整行 | 视题干变，多要素清晰分栏 |
| **适用场景** | 求稳、怕超字、临场没时间雕琢概括词 | 文字功底好、追求层次感与政务语感 |
| 实例 | 「推广铁路运输。与上级部门协同推进…」 | 「举措 1:… / 成效 1:…」 |

**差异对照五项**：① 各自多踩/漏了哪个采分点 ② 分类逻辑差异 ③ 各自适用场景 ④ 各自风险（小马哥易结构松散；白鹭易分栏过细、易超字） ⑤ **落点：帮使用者判断"我更适合哪一套"**。

> **诚实边界**：某些环节两版**其实不分歧**（如概括词需统一句式），
> **必须直说"此处几版一致"**，不得为了凑对照而编造差异。差异来源详见白鹭库第八节。

## 二、用户作答评判

**评分 = 采分点覆盖法（子项逐条核对）**：拆子项 → 逐条核对（踩到≥80%满分／40–80%一半／<40%零分）→ 汇总。

**核心规则**：

- 申论踩点**加分制，不存在倒扣**；编造内容不得分但不额外扣分
- 口语化不单独扣分，但命中不了采分点关键词 → 该项不得分
- **概括词必须来自材料，禁止自创**
- 答案不写任何非得分句
- **不做错别字检查**（除非用户明确要求）；表述问题只给规范替换建议

**评分必须使用题目实际分值**，不是百分制。完整评分方法与格式模板见 `references/scoring-rules.md`。

作答铁律（字数/句子结构/去水/概括词/自检）见 `references/writing-rules.md`。
手写作答照片：**不因拍照质量（模糊、光线、倾斜）扣分**；字迹与卷面只在无题干模式下按兜底模式评定。

### 若用户上传的是机构机改／解析截图

**判定为"真题识别 + 采分点校准"任务**，不是普通做题：

1. 逐字提取：**原题题干、参考答案、得分分析（各维度得分/丢分）、优缺点诊断、材料段落解析**
2. **深度复盘**：用户作答（或此前给出的某版答案）在机改中**丢分的确切原因**——缺哪个采分词、格式漏了什么、归并颗粒度差异
3. **校准点池**：按 `references/scoring-rules.md` 第四节的三阶证据等级（核心硬点／提示补充／争议项），判断机构答案里哪些是本考点、哪些只是措辞偏好
4. **不新设机构专属方法论文件**；若确属我方方法论缺失（不是本题个例），先说明拟改内容、经用户确认后再写入 `references/xiaoma-methodology.md` 或 `references/bai-lu-methodology.md`
5. **一次只沉淀一道题的规律**，不推倒重写

## 三、公文写作题补充

**格式先于内容**：动笔前必须先读 `references/gongwen-format-rules.md`，按文种确定属于四类格式中的哪一类，并**先预留格式占格**：

- **全格式**（通知、通告、报告、请示、函、意见、倡议书、公开信、感谢信）：标题 1 行 + 称谓 1 行 + 落款 2 行 = **固定 4 行**
- **半格式一**（讲话稿、发言稿、致辞、讲解词、宣讲稿、经验交流发言稿）：标题 + 称谓 = **2 行**，**不写落款**
- **半格式二**（短评、网评、新闻稿、推荐材料、汇报材料、工作总结、调研报告、工作方案、汇报提纲）：**仅标题 1 行**
- **特殊格式**：简报（报头＋正文）、编者按（首行空两格"编者按："，无独立标题）、题干明示"不考虑格式"的内容要点

**内容选择**：按文种目的筛选要点——倡议书聚焦"为什么做／怎么做／怎么参与"；汇报、推荐材料聚焦"做法／成效／数据"；讲话稿重身份感与号召力。

**结构标识**：汇报提纲、调研提纲、工作方案须**显性写出**"背景／做法／成效／结语"等结构词，这是独立采分点。

**语言风格**：倡议书需感染力与号召结尾；报告、提纲需客观简洁，不堆形容词。

**格式分不可省**：参评材料、汇报材料、通知、倡议书**漏落款（机关＋日期）直接扣分**；标题严禁加书名号，称谓后必须换行写正文。

## 四、反馈输出

**默认用精简格式**；用户说"展开"/"详细"才切换详细格式。格式模板见 `references/scoring-rules.md`。

**输出顺序**（改进建议优先，不做诊断）：

1. 必须补的失分点（2-3 个，各附"影响哪个维度 + 怎么改"）
2. 表述升级（口语化 → 申论规范表述，见 `../shared/references/expression-upgrade-rules.md`）
3. 成语与名言可用之处
4. 论证思路怎么改
5. 优化示范（挑 1-2 句改写对比）
