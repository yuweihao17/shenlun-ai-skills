# 2026年国家公务员考试申论（行政执法卷）

## 全卷概况

- **考试名称**：2026年国家公务员考试申论（行政执法卷）
- **试卷主题**：新时代行政执法方式演进、法治温度与智慧监管校准
- **给定材料概要**：材料1以鲁师傅广合烧饼“四个台阶”展现广合县市场监管部门从没收烤炉到备案规范、标准化帮扶、综合执法与品牌赋能、非现场监管与“无事不扰”白名单的演进；材料2讲威山森林派出所通过普法转产、机构改革警务协同与无人机红外智能警务实现盗猎盗伐零发案；材料3讲D市市场监管局郭队长查办婧心瑜伽馆、嘉力美健身中心、能易充公司三起消费维权案（刚柔并济、包容审慎）；材料4讲B市政务云数据中心运维团队7×24小时守护民生数据、应急处突与主动防御；材料5讲E市“非现场监管”试点遇阻后主动暂停3个月调研修正，实现从“管得住”到“管得好”的跨越。

## 各题详情

### 第1题
- **题型**：归纳概括题（变化类，不写总括句）
- **分值**：15分
- **原题**：请结合“给定资料1”中鲁师傅广合烧饼发展过程中的四个台阶，谈谈广合县市场监管部门的执法方式发生了哪些变化。（15分）要求：全面、准确、有条理，不超过300字。
- **关键词**：鲁师傅、广合烧饼、四个台阶、流动摊贩备案、小吃一条街、联合检查、五个统一、示范店、专项扶持贷款、市场监管局、一次检查、地理标志证明商标、非现场监管、阳光厨房、智食链、无事不扰白名单、体检报告
- **阅卷采分点**：
  1. 第一台阶（流动摊贩→固定商户）：由直接没收烤炉变为试点备案办证、讲解政策；规划小吃街劝导入驻，工商与卫生联合用专业工具规范检查并核发登记卡 — 4分
  2. 第二台阶（个体户→现代商户）：整合工商质监；由凭经验经营变为推行“五个统一”标准化、参观示范店、提供专项贷款、上门指导装修及评优授牌扶持 — 4分
  3. 第三台阶（普通店铺→金字招牌）：三局合并为市场监管局，由多头重复检查变为一次综合检查减负；协调成立行业协会、请专家分析工艺助申地理标志证明商标 — 3.5分
  4. 第四台阶（传统作坊→现代企业）：由进门检查变为门口扫码“非现场监管”（“阳光厨房”直连、智能传感器监测、“智食链”溯源）；纳入“无事不扰”白名单并推送“体检报告” — 3.5分

### 第2题
- **题型**：综合分析题（词句理解+原因分析，必须写总括句）
- **分值**：10分
- **原题**：“给定资料2”中毛所长说：“现在，我们已经可以从核心保护区撤离到林区边缘，把这片林海完完整整地还给大山了。”请根据“给定资料2”，谈谈毛所长这句话的意思，以及他为什么这么说。（10分）要求：理解准确，内容全面，条理清晰。不超过250字。
- **关键词**：威山自然保护区、威山森林派出所、毛所长、核心保护区、生态保护夜校、生态旅游、生态守护志愿队、机构改革、警种壁垒、零发案、智能警务、无人机巡防、视频监控、红外相机
- **阅卷采分点**：
  1. 句意阐释：核心保护区生态执法不再依赖人力蹲守，民警可撤至林区边缘，减少人为干扰，让生态系统自我修复、野生动物享有更自然生存环境 — 3分
  2. 群众支持/观念转变：开夜校方言普法、建议镇政府引导转型生态旅游增收、建志愿队宣传，村民从排斥转向主动巡逻并救助野生动物 — 2.5分
  3. 机构改革/警务协同：森林公安自上而下改革破除警种壁垒，联动驻地派出所搜集线索，2023年末至今实现盗猎盗伐零发案 — 2分
  4. 科技赋能/智能警务：智能与传统警务结合，利用无人机巡防、布设视频监控和红外相机预警震慑，效率远高于人力蹲守 — 2.5分

### 第3题
- **题型**：公文写作题（汇报提纲——半格式二：居中标题+正文）
- **分值**：20分
- **原题**：D市市场监管局拟召开月度工作总结会。假如你是郭队长，请根据“给定资料3”，拟写一份关于三个案例的执法情况汇报提纲。（20分）要求：（1）包括三个案例的基本情况、执法过程及处理结果；（2）要点全面，层次分明；（3）不超过400字。
- **关键词**：郭队长、婧心瑜伽馆、入会协议书、格式条款、嘉力美健身中心、提示章、不退不换不转、能易充、0.09元、默认勾选、不予行政处罚、严肃批评
- **阅卷采分点**：
  1. 格式规范：居中标题，提纲不写称谓与落款，层次分明 — 2分
  2. 婧心瑜伽馆案（基本情况+执法过程+处理结果）：接多起投诉协议不退费且意外免责、拒退术后会员费；现场检查约谈释明属无效格式条款；依法罚款、责令退款并改协议，现已退费并明确可协商退费 — 6分
  3. 嘉力美健身中心案（基本情况+执法过程+处理结果）：接两起投诉收据加盖拒退提示章；约谈驳斥选择性盖章与未获利辩解，认定单方封死退费违法；没收销毁印章、警告罚款、责令退费 — 6分
  4. 能易充公司案（基本情况+执法过程+处理结果）：居民反映App默认勾选0.09元保障费且取消隐蔽；体验核实并赴企调查，核查其主动整改设并列按钮并承诺全额退费；依法不予处罚、严肃批评、限期退款并优化界面 — 6分

### 第4题
- **题型**：公文写作题（推荐材料——半格式二：居中标题+正文）
- **分值**：20分
- **原题**：A省拟开展全省政务服务先进集体评选活动，B市准备推荐市政务云数据中心运维团队参选。请根据“给定资料4”，拟写一份推荐材料。（20分）要求：（1）紧扣资料，内容全面；（2）结构完整，语言流畅；（3）不超过450字。
- **关键词**：B市政务云数据中心运维团队、7×24小时、1000个工作日、扩容、0.28秒、30秒定位、柴米油盐、人工核验、渗透测试、同城双活+异地灾备、医保主节点宕机、离线结算通道、攻防实战演练、主动防御程序、网安则民安
- **阅卷采分点**：
  1. 格式与结构：居中标题、开头总体评价与1000个工作日成绩、主体分条事迹、推荐结语 — 3分
  2. 日常运维高效：监测养老金发放等高峰及时扩容（平均响应0.28秒），智能监控30秒定位老化设备故障并启备用通道 — 3.5分
  3. 为民底线意识：牢记数据连着柴米油盐，推行“指纹+身份证+人工核验”解老人刷脸难；摒弃麻痹主动渗透测试与漏洞扫描，筑牢同城双活+异地灾备架构 — 4分
  4. 应急处突果敢：立足充分预演，暴雨天医保主节点宕机时冒雨到岗、紧急启用医院离线结算通道，15分钟恢复且结算基本无误 — 3.5分
  5. 安全防御与严谨作风：复盘省演练失利，自研部署主动防御程序、升级安保至3.0，抵御境外黑客7小时攻击；晨会查变更单、全天候高音待命、熟记部门联络 — 6分

### 第5题
- **题型**：大作文（议论文）
- **分值**：35分
- **原题**：“给定资料5”中提到：“要获得真正的进步，不能只是一味往前跑，更关键的是要明确跑的目标。”请你对这句话进行深入思考，针对行政执法工作，联系实际，自选角度，自拟题目，写一篇文章。（35分）要求：（1）观点明确，见解深刻；（2）参考给定资料，但不拘泥于给定资料；（3）思路清晰，语言流畅；（4）字数1000-1200字。
- **关键词**：非现场监管、AI监管系统、E市、主动暂停、调整修正、往前跑、明确跑的目标、三级审核、线上智能监测+线下精准指导、管得住、管得好
- **主题类型（袁东框架）**：双主题 ABC 型（A=往前跑/技术赋能与机制创新，B=明确跑的目标/执法为民与法治初心、适时停顿校准，C=行政执法获得真正的进步/从“管得住”到“管得好”）
- **分论点方向**：
  1. A→C：积极“往前跑”，以机制革新与科技赋能提升执法精准度与效率（兼提盲目求快的风险）
  2. B→C：明确“跑的目标”，以法治精神与为民初心守住公平交易与民生底线
  3. A+B→C：将速度与方向有机统一，在主动暂停校准与“线上+线下”人机协同中实现质的飞跃
- **阅卷采分点**：
  1. 立意准确：紧扣行政执法工作，准确把握“往前跑”与“明确目标”的辩证关系 — 10分
  2. 结构清晰：按双主题 ABC 型三层展开，不重复、层次分明 — 7分
  3. 论证充分：结合材料5（E市暂停修正）并联动材料1–4案例，有机理分析与层级跃升 — 10分
  4. 语言流畅与规范：标题=总论点，首尾呼应，字数符合1000–1200字 — 8分
